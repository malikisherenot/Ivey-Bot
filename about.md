# Ivey Bot

Frame-accurate macro bot.

- Record and replay
- Position correction
- Own `.ivey` format
- Import `.gdr`, `.gdr2`, `.gdr.json`
- P1 only and 2P only recording
- Merge macros
- Swift clicks
- Frame stepper
- Prevent Death
- Show hitboxes and hitbox trail
- Show trajectory
- Video renderer with audio
- Window effects
